# DESERTER'S MOUNTAIN

A simple 2D-platformer made by following youtuber Brackey's tutorial called "How to make a Video Game - Godot Beginner Tutorial".
Link: https://youtu.be/LOhfqjmasi0?si=lI80x0Ko19jHEKmk


## CONTROLS:
  * **JUMP**: **SPACE**, **W** and **UP** arrow
  * **LEFT**: **A** and **LEFT** arrow
  * **RIGHT**: **D** and **RIGHT** arrow
